Employee Payroll System

Visual Basic Programming Project

Project Description

Developed a Visual Basic Windows Forms application to calculate employee payroll, including gross pay, overtime, taxes, and net pay.

Technologies Used

Visual Basic .NET, Visual Studio, Windows Forms

Project Features

  • Calculates employee gross pay
  • Calculates overtime pay
  • Calculates payroll taxes
  • Calculates employee net pay
