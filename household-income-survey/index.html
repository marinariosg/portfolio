Household Income Survey Application

Visual Basic Programming Project

Project Description

Developed a Visual Basic Windows Forms application for collecting and analyzing household income survey data in Cincinnati and Northern Kentucky. The application is designed to organize household information and calculate statistics by county and state.

Technologies Used

Visual Basic .NET, Visual Studio, Windows Forms

Project Features

  • Collects county, state, yearly income, and household size
  • Validates required survey information
  • Stores survey records using parallel arrays
  • Calculates total households surveyed by county
  • Calculates average household income by county
  • Calculates percentage of households in poverty
  • Displays survey results in a ListBox
