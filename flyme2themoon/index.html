FlyMe2theMoon - Flight Reservation System

Project Description

Developed a Windows Forms application using Visual Basic .NET and SQL Server to manage flight reservations, passenger information, and flight records.

Technologies Used

Visual Basic .NET, SQL Server, SQL, Windows Forms, and Visual Studio

Project Features

  • User login system with different roles
  • Passenger information management
  • Flight reservations and seat selection
  • Viewing past and upcoming flights
  • SQL Server database integration

What I Learned

Through this project, I gained experience developing Windows Forms applications, working with databases, writing SQL queries, and connecting a Visual Basic application to SQL Server.
